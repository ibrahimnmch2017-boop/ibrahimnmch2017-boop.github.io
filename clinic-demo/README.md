A self-initiated concept prototype and accessible design system for a boutique aesthetic dermatology clinic. Engineered entirely with vanilla HTML5 and custom CSS tokens for ultra-fast, sub-second page loads and fluid 60fps rendering without third-party framework overhead.

> **Note:** This is a demo template. All names, contacts, photos, and content are placeholders — not affiliated with any real clinic. Photos are generated placeholders; replace them with your own licensed assets before production use.

---

## 🎨 Design Philosophy & Tokens

The design language combines modern clinical trust with warm hospitality:

- **Primary Colors:** 
  - Deep Teal (`#0E7C93`) — Reflecting clinical precision and sterile calm.
  - Midnight Navy (`#123A5C`) — Conveying institutional trust and structure.
- **Warm Accents:** 
  - Teak Wood (`#7A5A24` / `#B88E4B`) — Grounding the interface with warmth.
- **Accessibility:** 
  - Every typography color pair is calibrated for 100% **WCAG AA contrast ratios** (minimum 4.5:1 for body copy).
  - Semantic HTML landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) ensuring screen-reader readiness.

## ⚡ Performance Characteristics

| Metric | Measurement | Note |
| :--- | :--- | :--- |
| **Framework Overhead** | **0 KB** | Pure Vanilla HTML5/CSS3 (No React, Vue, or Tailwind build bloat) |
| **First Contentful Paint (FCP)** | **< 0.4s** | Direct local rendering with zero external CDN dependencies for CSS/JS |
| **Asset Strategy** | **Self-Contained** | Local placeholder assets; no external tracking hotlinks |
| **Responsiveness** | **Fluid Grid & Flexbox** | Flawlessly adapting from mobile viewports (390px) to ultra-wide displays |
